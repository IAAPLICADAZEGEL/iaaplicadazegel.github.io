# 16. Ética, criterio y responsabilidad profesional

## 16.1. Generar contenido conservando el criterio profesional

### Mecanismo CREA

1. **Compilar**
   Reunir información, datos y fuentes.

2. **Reflexionar**
   Analizar el problema antes de generar una respuesta.

3. **Escribir**
   Construir una primera versión basada en criterio propio.

4. **Amplificar**
   Utilizar la IA para mejorar, estructurar, extender o transformar el trabajo.
