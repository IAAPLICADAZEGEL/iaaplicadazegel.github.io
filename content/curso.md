# Programa del curso

El programa avanza desde los fundamentos de la inteligencia artificial hasta la construcción de proyectos aplicados.

| Eje                          | Contenido                                                                                                             |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Fundamentos**              | Inteligencia artificial, IA generativa, modelos y principales conceptos necesarios para comprender su funcionamiento. |
| **Interacción con IA**       | Uso de asistentes de IA y estrategias para formular instrucciones efectivas.                                          |
| **Prompts**                  | Construcción, mejora e iteración de prompts según el resultado esperado.                                              |
| **Documentos y fuentes**     | Trabajo con archivos, fuentes primarias, búsqueda, extracción y organización de información.                          |
| **Datos**                    | Organización, análisis, interpretación y visualización de datos con apoyo de IA.                                      |
| **Gestión del conocimiento** | Uso de IA para trabajar con información propia, documentos, referencias y bases de conocimiento.                      |
| **Generación de contenido**  | Creación de textos, imágenes, presentaciones, recursos digitales y otros contenidos asistidos por IA.                 |
| **Automatización**           | Identificación de tareas repetitivas y construcción de soluciones que integren IA dentro de un proceso.               |

# Metodología

El curso utiliza una metodología principalmente **práctica y orientada a proyectos**.

Cada tema parte de una necesidad concreta y progresa desde la comprensión del problema hasta la construcción de un resultado funcional.

### Secuencia de trabajo

**Comprender → Aplicar → Verificar → Mejorar → Construir**

| Etapa          | Trabajo                                                              |
| -------------- | -------------------------------------------------------------------- |
| **Comprender** | Definir el problema, objetivo y resultado esperado.                  |
| **Aplicar**    | Utilizar una herramienta o modelo de IA sobre un caso concreto.      |
| **Verificar**  | Revisar la calidad y utilidad del resultado obtenido.                |
| **Mejorar**    | Iterar prompts, herramientas y procedimientos.                       |
| **Construir**  | Convertir lo aprendido en un producto, recurso o solución aplicable. |

Las sesiones combinan:

* Explicaciones técnicas.
* Demostraciones en vivo.
* Casos prácticos.
* Actividades guiadas.
* Trabajo con documentos y datos.
* Prompts y ejemplos reutilizables.
* Desarrollo progresivo de proyectos.

# Evaluación

La evaluación del curso se basa en **dos proyectos aplicados**.

| Evaluación                        | Proyecto                                                  |     Peso |
| --------------------------------- | --------------------------------------------------------- | -------: |
| **Evaluación continua / Parcial** | Proyecto de análisis de datos                             | **40 %** |
| **Evaluación final**              | Proyecto final según el perfil e intereses del estudiante | **60 %** |

---

## Evaluación continua / Parcial — 40 %

### Proyecto de análisis de datos

El estudiante desarrollará un proyecto en el que utilizará inteligencia artificial y herramientas de análisis para trabajar con un conjunto de datos.

El proyecto deberá demostrar la capacidad para:

* Comprender los datos disponibles.
* Organizar y analizar la información.
* Obtener resultados relevantes.
* Generar visualizaciones cuando corresponda.
* Interpretar y comunicar los principales hallazgos.

**Peso:** **40 % de la nota final.**

---

## Evaluación final — 60 %

### Proyecto aplicado

El estudiante desarrollará un proyecto final de acuerdo con su **perfil, área de interés o necesidad particular**.

Puede escoger una de las siguientes líneas:

| Línea                        | Proyecto                                                                                                |
| ---------------------------- | ------------------------------------------------------------------------------------------------------- |
| **Generación de contenido**  | Creación de una solución basada en IA para producir, transformar o gestionar contenido.                 |
| **Gestión del conocimiento** | Construcción de una solución para organizar, consultar, procesar o aprovechar información y documentos. |
| **Automatización libre**     | Desarrollo de una automatización aplicada a una tarea o proceso seleccionado por el estudiante.         |

El proyecto debe integrar las herramientas y técnicas desarrolladas durante el curso y presentar un resultado funcional.

**Peso:** **60 % de la nota final.**

## Resultado del curso

Al concluir el programa, cada estudiante habrá desarrollado al menos:

1. **Un proyecto de análisis de datos.**
2. **Un proyecto final aplicado a su propio perfil o área de interés.**

El objetivo es que el aprendizaje termine convertido en resultados que puedan reutilizarse fuera del aula.
