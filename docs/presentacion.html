MECÁNICA

¿Cómo se
evalúa el curso?

Dos proyectos sobre casos reales, con peso idéntico.

PROYECTO PARCIAL — 50 %

Análisis de datos aplicado a un problema propio.

Se entrega el caso, los datos trabajados y la decisión que sale de ellos.

PROYECTO FINAL — 50 %

Solución construida, documentada y en funcionamiento.

Se elige una de las tres rutas y se sustenta el resultado.
