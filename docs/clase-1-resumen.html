OBSERVACIÓN

Lo fácil para una persona puede ser extraño para el modelo.

Contar caracteres o ejecutar ciertos cálculos no se parece a resumir veinte páginas.

PRINCIPIO

Una continuación probable no equivale a una afirmación verdadera.

Fluidez y verdad son dimensiones distintas. Por eso necesitamos evidencia externa.

SISTEMA MODERNO

El modelo no trabaja solo.

01MODELO

Genera lenguaje y razona sobre el contexto disponible.

02CONTEXTO

Mensajes, instrucciones, fragmentos de archivos y resultados.

03HERRAMIENTAS

Búsqueda, código, cálculos, imágenes, archivos y conectores.

04PRODUCTO

Orquesta capacidades dentro de una experiencia utilizable.

VENTANA DE CONTEXTO

Finita

La conversación, las instrucciones, los documentos y la respuesta compiten por espacio.

INFORMACIÓN

Antes / ahora

Lo aprendido durante el entrenamiento no es lo mismo que un documento o dato recuperado durante la tarea.

COMPORTAMIENTO

No es neutral

Datos incompletos, sesgos, ajustes y sicofancia pueden influir en la salida.
