## Herramientas

> [Google Sites](https://sites.google.com/)
>
> [Netlify](https://www.netlify.com/)

## Acción

1. Tener listo el dashboard HTML del caso anterior.

2. Probar dos formas de publicación:

### Opción A — Google Sites

1. Crear un sitio en Google Sites.
2. Incorporar o enlazar el dashboard.
3. Publicar el sitio.
4. Abrir el enlace desde otro dispositivo.

### Opción B — Netlify

1. Ingresar a Netlify.
2. Crear un nuevo sitio.
3. Subir el archivo `index.html` o la carpeta completa del proyecto.
4. Esperar el despliegue.
5. Abrir la URL generada desde otro dispositivo.

3. Modificar algún elemento del dashboard y volver a publicarlo.

4. Comparar ambas alternativas según:

- facilidad de publicación;
- actualización;
- control sobre los archivos;
- acceso desde otros dispositivos;
- mantenimiento.

5. Verificar siempre que el enlace publicado funcione para otros usuarios y no únicamente desde la cuenta o equipo donde fue creado.
