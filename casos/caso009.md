## Acción

1. Realizar una consulta de bajo riesgo:

```text
¿Cuál es el atajo de teclado para insertar un salto de página en Microsoft Word?
````

2. Realizar una consulta de riesgo medio:

```text
Viajaré desde Perú a Chile por trabajo la próxima semana.
¿Qué documentos necesito para ingresar?
```

3. Realizar una consulta de alto riesgo:

```text
Desde RR. HH. debemos tomar una decisión laboral relacionada con la finalización del contrato de una trabajadora embarazada.

¿Qué establece la legislación peruana aplicable?
```

4. Cuando la consecuencia de un error sea importante, solicitar sustento:

```text
Sustenta esta respuesta con fuentes verificables.

Identifica:
- institución o autor;
- documento;
- fecha;
- enlace correspondiente.
```

5. Abrir y revisar las fuentes antes de usar la información.
6. Mientras mayor sea el riesgo, mayor debe ser la verificación y el criterio profesional aplicado.
