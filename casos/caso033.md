# Imagen Dirección del proceso

## Pasos

1. Comenzar con un borrador o una idea vaga de lo que queremos.
2. Ordenar la información disponible.
3. Solicitar recomendaciones e ideas.
4. Iterar hasta encontrar el resultado deseado.
5. Estructurar la idea final en un prompt.
6. Copiar el prompt final y utilizarlo en otro chat para generar la imagen.

# Ejemplo

## 1. Borrador inicial

```text
Estoy buscando un post promocional para mi empresa para la campaña de Navidad.
```

## 2. Organizar la información

```text
Organiza los datos de mi empresa utilizando el siguiente documento adjunto:

https://docs.google.com/document/d/1vZL0Wn3PlW8obDWAXBf9BgfewgyFItGCwlgXr7_yE6k/edit?usp=sharing
```

## 3. Solicitar recomendaciones

```text
Necesito que analices mi borrador de prompt y el documento adjunto.
"Estoy buscando un post promocional para mi empresa para la campaña de Navidad."

Proporciona 10 ideas de publicaciones si quiero lanzar una campaña promocional en Facebook.
```

## 4. Iterar la idea

```text
Trabajemos sobre esta idea.

Ayúdame a pulirla y proponme mejoras hasta obtener una versión que funcione bien como publicación promocional.
```

## 5. Convertir la idea en un prompt estructurado

```markdown
Ahora proporciona un prompt con la siguiente estructura:

## Objetivo
[Qué queremos generar.]

## Composición
[Qué queremos ver.]

## Estilo
[Cómo debe verse.]

## Formato
[Proporción de la imagen.]

## Etiquetas
[Características visuales.]

## Contexto
[Información adicional.]

## Plano
[Tipo de encuadre.]

## Ángulo
[Posición de la cámara.]
```

## 6. Generar la imagen

>
> Copia el prompt final y utilízalo en un nuevo chat para generar la imagen.
>
