## Acción

1. Separar la información estable de la empresa en archivos reutilizables:

```text
DATOS_empresa.md
SERVICIOS_empresa.md
ESTILO_escritura.md
GUIA_visual.md
CASOS_material.md
````

2. Adjuntar únicamente los archivos necesarios para cada tarea.

3. Para crear una publicación:

```text
Utiliza los archivos proporcionados como contexto.

Crea un post para Instagram sobre el servicio de evaluación inicial.
```

4. Para crear un guion:

```text
Utiliza los archivos proporcionados como contexto.

Escribe un guion breve para explicar este servicio en redes sociales.
```

5. Para crear una pieza visual:

```text
Utiliza los archivos proporcionados como contexto.

Diseña una pieza promocional 1:1 para este servicio respetando la identidad visual de la empresa.
```

6. Cuando cambie información estable, editar únicamente el archivo correspondiente y reutilizarlo en las siguientes tareas.
