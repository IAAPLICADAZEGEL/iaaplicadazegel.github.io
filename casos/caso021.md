## Recurso

> Archivo: `002-B-gastos_personales.xlsx`

## Acción

1. Adjuntar el archivo de datos.
2. Enviar:

```text
Convierte estos datos en un dashboard HTML interactivo y autocontenido.

Incluye todos los registros directamente dentro del archivo para que funcione sin depender del Excel original.

Debe incluir:

- gasto total;
- gasto promedio;
- cantidad de registros;
- evolución temporal;
- gastos por categoría;
- métodos de pago;
- principales gastos;
- filtros;
- tabla completa.

Genera todo en un único archivo HTML con CSS y JavaScript integrados.
````

3. Guardar el resultado como:

```text
dashboard_gastos.html
```

4. Abrir el archivo en el navegador.
5. Renombrar o mover el Excel original y comprobar que el dashboard siga funcionando.
6. Utilizar los filtros y gráficos para explorar los datos.
