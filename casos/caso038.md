# Generación profesional completa

# Bloque 1 - Generación de estilo y letra

## Prompt

```text
{ref}: Michael Jackson - Off the Wall
{objetivo}: Crear un jingle para Numera Consultores Contables, empresa ubicada en Lima y dirigida principalmente a contadores.

Analiza {ref} para identificar características musicales generales como energía, ritmo, instrumentación, estructura, producción y atmósfera.

Traduce esas características a términos musicales genéricos y técnicos, evitando imitar elementos distintivos o mencionar artistas y canciones en la salida.

El resultado debe ser profesional, comercial y optimizado para Suno y otros generadores de música con IA.

PARTE 1 — ESTILO MUSICAL

Entrega una sola línea de etiquetas separadas por comas.

Usa términos musicales técnicos y precisos para describir:
género, tempo, groove, instrumentación, tipo de voz, producción y atmósfera.

PARTE 2 — LETRA

Genera la letra completa del jingle adaptada a {objetivo}.

Usa etiquetas entre corchetes para definir la estructura y las instrucciones musicales, por ejemplo:

[Intro]
[Verse]
[Pre-Chorus]
[Chorus]
[Bridge]
[Guitar Solo]
[Outro]

Adapta la estructura, las secciones y la dinámica a las características musicales identificadas.

Usa paréntesis únicamente para ad-libs, respuestas vocales, coros secundarios u otros elementos que deban cantarse.
```

# Bloque 2 - Producción

## Pasos

1. Registrarse en **Flow Music**.
2. Crear una nueva sesión.
3. Copiar las etiquetas generadas en **Estilo musical**.
4. Copiar la letra generada en **Letra**.
5. Generar la canción.
