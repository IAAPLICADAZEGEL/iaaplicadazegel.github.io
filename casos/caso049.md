## Herramientas

> [Google Apps Script](https://script.google.com/)
>
> [Google Forms](https://forms.google.com/)
>
> [Google Sheets](https://sheets.google.com/)

## Premisa

Crear un sistema simple y minimalista para registrar ingresos y egresos personales mediante Google Forms y almacenar automáticamente los movimientos en Google Sheets.

## Prompt

```text
Genera un sistema simple, práctico y minimalista para registrar finanzas personales mediante Google Apps Script.

El sistema debe crear automáticamente un Google Form con los siguientes campos:

- 💰 Tipo de movimiento: Ingreso / Egreso
- 📝 Descripción
- 💵 Monto
- 📅 Fecha

Requisitos:

- utiliza emojis apropiados;
- todos los campos deben ser obligatorios;
- el monto debe aceptar únicamente valores positivos;
- vincula automáticamente el formulario con una Google Sheet;
- aplica un formato limpio y profesional a la hoja de respuestas;
- utiliza una estructura de código sencilla y fácil de mantener.

Al finalizar la ejecución muestra:

✅ SISTEMA CREADO

- URL para responder el formulario;
- URL para editar el formulario;
- URL de la hoja de cálculo.

Entrega todo el código completo de Google Apps Script en un único bloque, listo para copiar y ejecutar.
````

## Implementación

1. Ingresar a [Google Apps Script](https://script.google.com/).
2. Crear un proyecto nuevo.
3. Pegar el código generado.
4. Guardar y ejecutar.
5. Autorizar los permisos solicitados.
6. Abrir los enlaces generados.
7. Registrar un ingreso y un egreso de prueba.
8. Verificar los movimientos en Google Sheets.
