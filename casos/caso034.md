# Texto a imagen - Obteniendo el estilo

## Requerimientos

### Imagen de referencia

![](images/034_a.png)

### Borrador

```text
Un cuy ayudando a un emprendedor en un local de trabajo a hacer las cuentas en una laptop.
````

## Pasos

1. Ir a un chat con capacidad de analizar imágenes y adjuntar la imagen de referencia.
2. Solicitar una descripción técnica de la imagen, enfocada solo en el estilo.
3. Pedir que adapte ese estilo a la idea del borrador.
4. Usar el prompt final para generar la imagen.

## Prompt 1 - Analizar el estilo de la imagen

```text
Analiza la imagen y proporciona una descripción técnica de la imagen.

Deseo obtener:
- solo el estilo

La descripción debe ser precisa si necesito emplearla en otros proyectos.

Formato de salida: texto plano.
```

## Prompt 2 - Adaptar el estilo a la idea

```text
Ahora emplea esa descripción y adáptala a mi idea:

"Un cuy ayudando a un emprendedor en un local de trabajo a hacer las cuentas en una laptop".

Devuelve un prompt profesional en texto.
```

## Prompt 3 - Generar la imagen

```text
Usa el prompt profesional anterior para generar la imagen.
```
