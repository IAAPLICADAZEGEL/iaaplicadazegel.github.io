## Herramientas

> [Google Apps Script](https://script.google.com/)
>
> [Google Forms](https://forms.google.com/)
>
> [Google Sheets](https://sheets.google.com/)

## Premisa

Automatizar un flujo básico de captura de información:

**Google Form → Procesamiento → Google Sheets**

Ejemplo: encuesta de entorno laboral para Recursos Humanos.

---

## Paso 1 — Diseño de preguntas

```text
Diseña 20 preguntas estratégicas para una encuesta de entorno laboral dirigida por Recursos Humanos.

Organízalas en 5 bloques temáticos con 4 preguntas por bloque.

Utiliza variedad de tipos de respuesta:
- escala;
- opción múltiple;
- casillas;
- respuesta corta;
- respuesta abierta.

Incluye emojis apropiados en los títulos de las secciones.

Optimiza la estructura para implementarla posteriormente en Google Forms.

Devuelve las preguntas organizadas por sección e indica el tipo de respuesta recomendado para cada una.
````

---

## Paso 2 — Generación del sistema

```text
Genera un código completo de Google Apps Script que cree automáticamente un sistema de encuesta de entorno laboral.

El script debe:

- crear un Google Form;
- incluir las 20 preguntas organizadas en 5 secciones;
- aplicar los tipos de respuesta y validaciones correspondientes;
- vincular automáticamente una Google Sheet para almacenar las respuestas;
- aplicar formato profesional a la hoja de resultados;
- utilizar funciones modulares y código organizado;
- incluir emojis en títulos y secciones cuando corresponda.

Al finalizar la ejecución debe mostrar:

✅ SISTEMA CREADO

- URL del formulario para responder;
- URL del formulario para editar;
- URL de la hoja de resultados.

Entrega todo el código completo en un único bloque listo para copiar y ejecutar.
```

---

## Paso 3 — Implementación

1. Ingresar a [Google Apps Script](https://script.google.com/).
2. Crear un proyecto nuevo.
3. Eliminar el código inicial.
4. Pegar el código generado.
5. Guardar.
6. Ejecutar la función principal.
7. Autorizar los permisos solicitados.
8. Revisar los enlaces generados.
9. Probar el formulario y verificar que las respuestas lleguen a Google Sheets.

---

```text
Devuelve una versión completa, funcional y lista para reemplazar el código anterior.
```
