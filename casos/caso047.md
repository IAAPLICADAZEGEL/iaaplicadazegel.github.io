## Premisa

ZELIMAR necesita un sistema contextual que reciba una imagen promocional y genere textos listos para publicar en redes sociales.

## Prompt — Planificador del sistema contextual

```text
Necesito crear un sistema contextual para ChatGPT Projects o Claude Projects llamado "Sistema Contextual Contenido".

Su función será recibir una imagen promocional o infografía de ZELIMAR y generar textos listos para publicar.

Fuente principal:
- ZELIMAR ficha base.

El sistema debe analizar la imagen y generar versiones optimizadas para:

1. Facebook
2. Instagram — publicación
3. Instagram — historia
4. TikTok

El tono debe ser:
- cercano;
- claro;
- cálido;
- profesional;
- casual;
- preciso.

Debe utilizar correctamente los datos, contactos y enlaces oficiales de la empresa.

Reglas:
- no inventar información;
- no repetir literalmente todo el texto de la imagen;
- adaptar llamadas a la acción según la plataforma;
- usar emojis y hashtags con moderación;
- preguntar solo si falta información indispensable.

La salida debe quedar lista para copiar y publicar.

Todos los archivos del sistema estarán en la raíz del proyecto, sin carpetas.

Planifica la cantidad mínima de archivos necesarios e indica para cada uno:
- nombre;
- función;
- contenido.
````

## Continuación — Generación de archivos

```text
Genera todos los archivos del sistema contextual en formato TXT.

Deben estar completos, listos para usar y ubicarse en la raíz del proyecto.

Genera primero el archivo principal de instrucciones y después los archivos complementarios.
```

## Flujo de uso

1. Crear un proyecto en [ChatGPT](https://chatgpt.com/) o [Claude](https://claude.ai/).
2. Cargar la ficha base y los archivos del sistema.
3. Adjuntar la imagen.
4. Escribir:

```text
Inicia
```

5. El sistema genera las versiones para Facebook, Instagram, Instagram Stories y TikTok.
